**Project Description**:

***SkillSwap*** is a full-stack MERN application that enables users to connect and exchange skills through a community-driven platform. Instead of traditional paid learning, users can create profiles **showcasing the skills they can teach and the skills they want to learn**, making it easier to find like-minded people for **collaborative learning and knowledge sharing**.

The platform provides a secure authentication system with JWT-based authorization, password encryption using bcrypt, and protected routes to ensure user data remains safe. New users complete an onboarding process to build detailed profiles, including their bio, profile picture, languages, and skills. Based on this information, SkillSwap recommends relevant users who are not already connected, allowing users to discover potential learning partners efficiently.

Users can send, receive, and accept skill exchange requests, creating meaningful connections within the platform. Once connected, they can communicate through real-time messaging powered by Stream Chat, enabling seamless discussions and planning for skill exchange sessions. The application follows a modular backend architecture using Express.js and MongoDB with Mongoose for efficient data management and scalable API development.

The frontend is built with React, providing a modern, responsive, and intuitive user interface that delivers a smooth user experience across devices. Together, the frontend and backend demonstrate complete full-stack development practices, including authentication, RESTful APIs, database design, state management, protected routes, real-time communication, and responsive UI development, making SkillSwap a practical and scalable platform for collaborative learning.
